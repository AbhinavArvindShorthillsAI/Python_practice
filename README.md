# Python Practice Set 3 
<b> This practice Set deals with scoping of variables in python <b>

<b>Scope in Python refers to the region of a program where a variable is accessible. When a variable is declared, it is only available within a specific scope, determining how long the variable exists and where it can be used. Python follows the LEGB rule to resolve variable scope:<br>
L (Local Scope): Variables defined within a function and accessible only inside it.<br>
E (Enclosing Scope): Variables in an outer function, accessible inside inner functions.<br>
G (Global Scope): Variables defined at the top level of a script or module.<br>
B (Built-in Scope): Predefined names like len()  and print() available everywhere.<br></b>
